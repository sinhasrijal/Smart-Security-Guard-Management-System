# 🛡️ Security Guard Attendance System

A digital attendance management system for security guards and security agencies. The application helps businesses track daily attendance, working hours, and guard deployment efficiently.

## ✨ Features

* 👮 Guard login
* 🕐 Daily check-in & check-out
* 📍 GPS location verification
* 📸 Selfie/photo attendance
* 📊 Attendance history
* 👨‍💼 Admin dashboard
* 📄 Attendance reports
* 🏢 Multiple guard/location management

## 🛠️ Tech Stack

* **Frontend:** Flutter & Dart
* **Backend:** Firebase
* **Database:** Cloud Firestore
* **Authentication:** Firebase Authentication
* **Storage:** Firebase Storage
* **Location:** GPS

## 🔄 Attendance Flow

```text
Login
  ↓
Start Duty
  ↓
GPS Verification
  ↓
Selfie
  ↓
Check-In Recorded
  ↓
End Duty
  ↓
Check-Out Recorded
```
